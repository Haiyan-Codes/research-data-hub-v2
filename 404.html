Research Data Hub · 科研数据平台

    
为心理健康及相关研究领域的科研人员设计：一站式检索三大公开学术 API（PubMed / Crossref / Semantic Scholar），获取文献与数据集信息。


    
文献研究智能体

    
    
      
  • 关键词驱动检索：PubMed / Crossref / Semantic Scholar 三源文献爬取 + Zenodo 数据集，按 DOI/PMID/标题去重。
    • 
      
  • 结构化中文研究摘要：从标题、摘要自动提取研究对象、方法学、样本量、核心发现四要素。
    • 
      
  • 文献计量分析：年份分布、高产作者、核心期刊、高频关键词、高被引 Top 10 可视化。
    • 
      
  • 研究洞察：主题聚类（基于关键词相似度）、引用脉络时间线、研究空白识别、推荐下一步研究方向。
    • 
      
  • 可下载报告：一键生成 Markdown 综合报告，包含全部文献与数据集。
    • 
    


    
文献与数据检索

    
    
      
  • PubMed E-utilities (NCBI)：文献元数据，返回 PMID、标题、作者、期刊、年份。官方文档
    • 
      
  • Crossref API：DOI 注册中心，返回 DOI、被引数、全文链接。官方文档
    • 
      
  • Semantic Scholar API：学术元数据，返回引用计数、TLDR。官方文档
    • 
      
  • Zenodo API (CERN)：开放存储数据集，按 record id / DOI 可溯源到原始上传者、文件、许可证。官方文档
    • 
      
  • 合并策略：按 DOI / PMID / Zenodo record id / 精确标题去重；去重前后条数均显示。
    • 
    


    
隐私说明

    
    
      
  • 检索请求从浏览器直接发送到官方接口（CORS 支持）。
    • 
      
  • 上传的数据文件和分析结果仅在当前浏览器会话中可用。
    • 
      
  • 收藏夹保存在 localStorage（本机浏览器）中，可一键导出 CSV。
    • 
      
  • 访问密码：mental_health（在 index.html 内修改 var PASS='…'）。
    • 
    


    
部署方式

    
    
      
  • 站点由 index.html + datasets.js 组成，无需服务器。
    • 
      
  • Fork 仓库后 push 到 GitHub，启用 Pages 即可获得独立访问地址。
    • 
      
  • 修改密码：编辑 index.html 中的 var PASS='…'。
    • 
      
  • 一键部署脚本：deploy_research_hub.ps1。
